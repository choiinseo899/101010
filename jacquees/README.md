# Jacquees — King of R&B (Fan Showcase)

DESIGN.md(Stink Studios 레퍼런스)를 기반으로 만든 Jacquees 소개 웹사이트입니다.

## 파일 구조

```
jacquees/
├── index.html        ← 분리 버전 진입점
├── css/style.css     ← 전체 스타일 (디자인 토큰, 애니메이션, 반응형)
├── js/data.js        ← 곡·앨범·타임라인·투어 데이터 (여기만 고치면 내용이 바뀜)
├── js/player.js      ← 재생, 가사(LRCLIB), Apple Music 스타일 가사 화면, 드래그&드롭
├── js/main.js        ← 페이지 인터랙션 (커서, 히어로, 타임라인, 앨범, 마퀴, 투어 등)
└── dist/jacquees.html ← 위 파일을 한 개로 합친 버전 (더블클릭으로 바로 열기)
```

## 바로 보기

- `dist/jacquees.html`을 브라우저로 열면 됩니다. (인터넷 연결 필요: 앨범 아트·미리듣기·가사를 실시간으로 불러옵니다)
- Netlify에 올릴 때는 `jacquees` 폴더를 통째로 Netlify Drop(app.netlify.com/drop)에 끌어다 놓으면 됩니다.

## 음악과 가사

- **재생**: iTunes Search API의 공식 30초 미리듣기를 사용합니다. 앨범 커버도 같은 API에서 불러옵니다.
- **가사**: LRCLIB(lrclib.net)의 시간 동기화 가사를 불러와 Apple Music처럼 한 줄씩 하이라이트합니다. 가사 텍스트는 코드에 포함되어 있지 않습니다.
- **미리듣기 싱크**: 30초 미리듣기가 곡의 어느 지점인지 API가 알려주지 않아서, 가장 많이 반복되는 줄(후렴)의 시작점으로 자동 추정합니다. 어긋나면
  - 지금 들리는 가사 줄을 **클릭**하면 그 줄에 싱크가 맞춰지고, 곡별로 브라우저에 저장됩니다.
  - `−0.5s / +0.5s`로 미세 조정, `AUTO`로 초기화할 수 있습니다.
- **전체 곡 재생**: 갖고 있는 음원 파일(mp3, m4a 등)을 페이지에 **끌어다 놓으면** 전체 곡으로 재생되고 가사가 처음부터 정확히 맞습니다. 파일 이름에 곡 제목이 들어 있으면(예: `Jacquees - B.E.D..mp3`) 그 곡에 자동으로 연결됩니다.
